# Olist E-Commerce Data Analysis

## Project Overview
This project analyzes the Olist Brazilian E-Commerce dataset to understand order patterns, customer reviews, order values, and delivery performance.

## Objectives
- Analyze e-commerce order data using Python.
- Clean and prepare datasets using Pandas and NumPy.
- Use SQL queries to analyze business data.
- Visualize order value and delivery-related insights.
- Calculate the 95% confidence interval for average order value.
- Compare weekday and weekend order counts.

## Tools and Technologies
- Python
- Pandas
- NumPy
- SQL
- SQLite
- Matplotlib
- CSV datasets

## Project Files
- `main.py` — Python analysis code.
- `olist_analysis.csv` — Processed analysis dataset.
- `order_value_graph.png` — Order value visualization.
- `delivery_review_graph.png` — Delivery and review visualization.

## Key Findings
- Average order value: 160.58 dataset units.
- Average review score: 4.09 out of 5.
- 95% confidence interval for average order value: 159.20 to 161.95.
- Weekday orders: 76,594.
- Weekend orders: 22,847.
- São Paulo (SP) had the highest order count among the states shown in the analysis.

## Business Recommendation
The business should monitor delivery performance and customer reviews to identify opportunities to improve customer satisfaction. It should also study purchasing patterns across weekdays and weekends to plan marketing activities.

## How to Run
1. Install Python.
2. Install the required libraries: `pandas`, `numpy`, and `matplotlib`.
3. Keep the original dataset CSV files inside the `data` folder.
4. Run `main.py` from the project folder.
